01

THE FILE项目档案

一张卡
说清一个项目

项目不是一行待办。它有状态、有进度、有截止日期、有一串还没做的下一步。这些信息集中在一张卡上，点开就是全部，不用在五个页面之间找。

A四种状态

构思中、进行中、搁置中、已完成。每个状态有自己的颜色，扫一眼就知道哪些在动、哪些卡住了。搁置不是失败，它只是暂时不占用注意力。

B进度两种算法

手动拖动滑块，或者交给待办自动计算——勾掉一条，进度就往前走一格。两种模式随时切换，不会丢数据。

C待办挂在项目下

每条待办都能单独勾选、删除、计数。项目层面的「下一步」不再散落在便签和脑子里。

D六种标记色与标签

朱砂、松石、暮紫、赭石、靛蓝、橄榄。配合自由标签，用来区分领域而不是优先级——优先级应该由顺序表达。

02

THE ORDER排序与归档

列表会
自己排队

默认按最近更新排序，也可以按截止日期、进度、创建时间。当你对顺序有自己的判断时，直接拖。

A拖动即排序

拖到哪张卡上，就和它换位。交换而不是插入，卡片高度不齐也不会错位。松手自动切到「自定义顺序」，刷新后保留。

B键盘等价操作

Alt + 方向键把当前卡片挪一位。不想动鼠标的时候，顺序照样能调。

C搜索与筛选

按 / 直接搜索项目名、描述或标签。状态筛选标签上带实时计数，筛完就知道还剩几个。

D做完了就收起来

只有「已完成」的项目可以归档。归档只是收起，编号从 NO.03 变成 A.01，内容一条不删，随时能还原。

03

THE MESS线索板

想不清楚的时候
先贴上去

每个项目在成为项目之前，都是一堆照片、句子和没连起来的念头。线索板是给那个阶段的——它不要求你先想明白。

A便签 / 照片 / 连线

空白处按 N 新建便签，直接上传照片，两个东西之间可以拉一条线。堆叠把相关的折成一摞，板面不会失控。

B独立一层，不干扰档案

线索板铺满整屏，返回档案时原来的筛选和滚动位置都还在。它是并列的第二块桌面，不是第六种状态。

04

THE GROUND界面配色

十五种纸
一种逻辑

版式是固定的：0 圆角、1px 发丝线、8px 网点。变的只有纸和墨。所以换配色不会把界面搞乱——它只是换了一种印刷。

A十五套，都做过对比度校验

正文对比度 ≥ 7:1，辅助文字 ≥ 4.5:1。深色纸不是把白纸反相，每一套都单独调过墨阶。

B强调色可换，也可取色

九种预设强调色，外加一支吸管。改的只是那一个信号色，层级和留白不动。

05

THE VAULT数据与 AI

AI 是可选件
数据是你的

没有云端账号，没有同步服务，没有「升级到专业版」。你的档案留在本机，AI 只是一个你可以选择接不接的外挂。

A不填 Key 就完全不联网

AI 默认关闭。要用的时候自己填 API Key 和接口地址，兼容 OpenAI 格式。不填，程序一个请求都不发。

B两种用法

整理现有项目（补描述、并标签、校准进度），或把一段乱写的备忘拆成几张能做的卡。改完要你确认才写入。

CJSON 导入导出

导出是一份带版本号的 JSON，导入会校验格式。换机器、做备份、存进网盘，都只是复制一个文件。

D本地存储，重启不丢

数据写在系统分配给本程序的本地存储里。安装包升级沿用同一个数据目录，改名也不会让旧档案消失。
